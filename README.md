# CYBER-TRACKER 365

Личный трекер силовых, калистеники и режима сна. Тёмная консоль в духе
операционного центра, светлая тема переключателем, адаптив от телефона
до широкого монитора.

Чистый HTML5 + ES6-модули, **без сборки**. Загружается на GitHub Pages как есть.
Supabase отвечает за авторизацию с обязательным подтверждением почты,
профиль и хранение записей.

---

## Что отслеживается

**Норма недели — 3 тренировки в зале.** Не выполнили — садится «батарея»:
интерфейс подсвечивается красным, коуч начинает писать про откат.

### Трек A — калистеника и гибкость

| Цель | Как считается |
|------|---------------|
| Шпагат | минуты растяжки + измеренный угол в тазу |
| Горизонт | время удержания + состояние прогрессии |
| Стойка на руках | время баланса + число попыток |

### Трек B — силовые

| Цель | Как считается |
|------|---------------|
| Жим лёжа | расчётный 1ПМ, рабочий вес, повторения |
| Присед | расчётный 1ПМ, тоннаж |
| Становая в сумо | расчётный 1ПМ, целевой вес, повторения |

1ПМ считается смесью формул Эпли и Бжицки — устойчиво на 1–12 повторениях.

### Сон

Цель по умолчанию — **подъём в 05:00** при норме сна 7 ч 30 мин, допуск ±15 минут.
Считаются: средний подъём за 14 дней, отклонение от цели со знаком, серия
попаданий подряд, процент попаданий, долг сна за неделю и рекомендуемое время отбоя.

График показывает время подъёма по дням с горизонтальной линией цели и зоной допуска —
точка выше линии означает, что проспали.

Дата записи — это **день пробуждения**. Отбой в 23:40 и подъём в 05:10 считаются
одной ночью длиной 330 минут, а не отрицательным интервалом.

## Разделы

| Раздел | Что внутри |
|--------|-----------|
| **Обзор** | уровень и опыт, норма недели, батарея, сон за сегодня, ближайшие задачи, коуч |
| **Тело** | карта мышц (спереди/сзади), нагрузка за 2 недели, дерево протоколов |
| **Сон** | запись ночи, метрики за 14 дней, график подъёмов, журнал ночей |
| **Журнал** | календарь активности, соблюдение нормы, последние записи |
| **Аналитика** | радар подготовки, динамика по каждой цели, объём за 30 дней, достижения |
| **Арсенал** | снаряжение с множителями опыта, челленджи |

На десктопе — сайдбар слева и контент в две колонки. На телефоне — нижний таббар,
свайпы между разделами и круглая кнопка быстрой записи.

## Игровой слой

Опыт и очки начисляются за тренировки, рекорды, попадания в режим сна и челленджи.
Очки тратятся на снаряжение, которое даёт множитель опыта (множители перемножаются).

**Челленджи** привязаны к протоколам и открываются, когда рекорд подходит к цели.
Урон засчитывается только по реальным цифрам: нужно превысить 60% собственного
лучшего результата, иначе противник восстанавливается.

### Скрытая консоль

5 нажатий на логотип или клавиша `` ` ``. Коды можно набирать и прямо в интерфейсе.

| Код | Действие |
|-----|----------|
| `idqd` | режим бога — тройные награды, четырёхкратный урон |
| `give_shards` | 9999 очков |
| `matrix` | фон с падающим кодом |
| `seed` | демо-данные: 10 недель тренировок и 8 недель сна |
| `exp <n>`, `stats`, `crit`, `wipe`, `help` | утилиты |

`iddqd` и `idkfa` работают как старые псевдонимы.

## Запуск

```bash
npm run dev      # http://localhost:4173
npm test         # сквозной тест без браузера, 47 проверок
npm run check    # синтаксис всех модулей
```

Ни сборщика, ни транспайлера, ни зависимостей в рантайме.

### GitHub Pages

1. Запушить в `main`.
2. **Settings → Pages → Source: GitHub Actions.**
3. `.github/workflows/pages.yml` прогоняет тест и деплоит.

Файл `.nojekyll` нужен, чтобы Jekyll не съел каталог `src/`.

### Supabase

Пошагово — в [`supabase/README.md`](supabase/README.md). Коротко:

1. Ключи уже в `src/config.js`.
2. Выполнить `supabase/schema.sql` в SQL Editor.
3. **Authentication → Providers → Email → включить «Confirm email».**
4. Прописать Site URL и Redirect URLs.

**Локальный режим.** Пока сервер не настроен или недоступен, приложение работает
целиком на `localStorage` и честно пишет об этом в шапке. Ничего не падает
и не зависает.

### Решения, о которых стоит знать

- **Никакого 3D, никаких `.gltf`.** Анатомия — инлайновые SVG-полигоны,
  эффекты — 2D canvas. Первая отрисовка практически мгновенная.
- **Цвета графиков читаются из CSS-переменных**, поэтому холсты сами
  перекрашиваются при смене темы, без отдельных палитр в JS.
- **`store.js` пересчитывает, компоненты подписываются.** Один `bus.emit('store')`
  перерисовывает всё. `bus.clear('store')` при пересборке дерева снимает утечку.
- **Осей радара не бывает больше 100%.** Многоугольник всё равно упирается
  во внешнее кольцо — подпись «107» спорила бы с фигурой. Перевыполнили цель —
  поднимите её в профиле.
- **Анимации на `transform` и `opacity`.** У `#app` в кадре появления только
  прозрачность: любой `transform`, кроме `none`, делает элемент containing block
  для `position: fixed`, и нижний таббар отрывается от экрана.

## Ограничения

- Клиент Supabase грузится с `esm.sh` в рантайме. В закрытой сети приложение
  уйдёт в локальный режим — это корректное поведение, но знать о нём стоит.
- Расчётный 1ПМ — это формула, а не замер. Смотрите на него как на линию тренда.
- Это дневник тренировок, а не медицинская или тренерская рекомендация.
  Тексты коуча — художественная часть интерфейса.
